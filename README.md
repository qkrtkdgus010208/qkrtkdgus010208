## 👨‍💻 About Me

> **MCU 레지스터 제어(ARM Cortex-M4 / AVR)와 모터·센서 제어부터 리눅스 커널 디바이스 드라이버, 온디바이스(Edge AI) 시스템까지 설계하고 최적화하는 임베디드 SW 엔지니어입니다.**

- 🐧 **Embedded Linux & Kernel Driver** : Jetson Orin Nano 리눅스 커널 5.15 캐릭터 디바이스 드라이버(`.ko`) 3종 설계, 엔코더 FSM 채터링 차단 및 `wait_queue` 블로킹 I/O 구현
- 🧠 **On-Device Edge AI & Smart Factory** : Jetson ↔ STM32 양방향 UART 공정 제어, Linux `v4l2-ctl` 하드웨어 카메라 튜닝 및 `QThread` 비동기 파이프라인 개발
- ⚡ **Automotive & MCU Control** : ARM Cortex-M4 레지스터 직접 제어(`RCC`, `TIM`, `SysTick`, `USART`), DC/서보 모터 PWM 불감대 보정 및 급변속 방지 안전 인터락 구현
- 🤖 **Autonomous Robotics** : ATmega128 3종 타이머 분리 설계, 하강 에지 동기화 기반 3채널 초음파 시분할 스케줄러 및 5-State 자율주행 FSM 구현
- 🧩 **SW Architecture & Optimization** : 인터페이스 기반 모듈형 상태 머신(FSM) 설계 및 `Object Pool` 정적 메모리 재사용을 통한 런타임 프레임 최적화
